{{ 'Who can see it' if en else 'Qui peut le voir' }}

    {% if en %}
  • Only you, by default. Your contracts are not used to train any model and are not shown to other users.
  • People you explicitly share a record with (read & comment, or edit) see that record only, and the activity log shows who did what.
  • Signatories and approvers see the text you send them through their private link, and nothing else.
  • The site administrators can technically access the database for maintenance and support; they do not browse contracts.
    • {% else %}
  • Vous seul, par défaut. Vos contrats ne servent pas à entraîner un modèle et ne sont montrés à aucun autre utilisateur.
  • Les personnes avec qui vous partagez explicitement une fiche (lecture et commentaires, ou modification) voient cette fiche uniquement ; le journal d'activité indique qui a fait quoi.
  • Les signataires et approbateurs voient le texte que vous leur envoyez par leur lien privé, et rien d'autre.
  • Les administrateurs du site peuvent techniquement accéder à la base pour la maintenance et l'assistance ; ils ne parcourent pas les contrats.
    • {% endif %}

{{ 'Encryption and deletion' if en else 'Chiffrement et suppression' }}

    {% if en %}
  • Files archived in the registry, signed PDFs and signature certificates are encrypted at rest (AES with an integrity check) before being written to disk{% if key_env %}; the key is held outside the data disk{% else %}; the key is stored on the server's data disk (the site operator can move it to an environment variable to keep it apart){% endif %}.
  • The text extracted from archived files is kept in the database so the global search can find it; the original files themselves stay encrypted.
  • Deleting a record or all your data overwrites then removes the files and removes the database rows. Backups made by the host before the deletion may persist for a limited time.
    • {% else %}
  • Les fichiers archivés au registre, les PDF signés et les certificats de signature sont chiffrés au repos (AES avec contrôle d'intégrité) avant d'être écrits sur le disque{% if key_env %} ; la clé est conservée hors du disque de données{% else %} ; la clé est conservée sur le disque de données du serveur (l'exploitant du site peut la déplacer dans une variable d'environnement pour la garder à part){% endif %}.
  • Le texte extrait des fichiers archivés est conservé dans la base pour que la recherche globale puisse le trouver ; les fichiers d'origine, eux, restent chiffrés.
  • Supprimer une fiche ou toutes vos données écrase puis supprime les fichiers et retire les lignes de la base. Les sauvegardes faites par l'hébergeur avant la suppression peuvent subsister un temps limité.
    • {% endif %}
